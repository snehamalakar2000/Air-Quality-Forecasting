   but artifacts/ is ignored and absent from GitHub, so the links return 404.

   Recommendation: either remove those links and say artifacts are generated locally, or publish the reference artifacts separately.
3. Generated/debug files are committed.

   The repository contains:
   - .DS_Store
   - docs/.Rhistory
   - ridge-diagnostic-before.txt
   The diagnostic file records failures from the older NumPy 2.2.6 environment and may confuse reviewers because the project now pins NumPy 2.3.5.

   Recommendation: remove generated files or clearly move historical diagnostics into a documented archive.
4. Configuration validation is incomplete.

   validate_config() checks timestamps and feature settings but does not proactively validate values such as:
   - empty model grids
   - negative n_estimators
   - invalid min_samples_leaf
   - invalid n_jobs
   - missing source metadata keys
   These errors may appear later as less-clear KeyError or scikit-learn errors.
5. Runtime metadata assumes pytest is installed.

   metadata() calls importlib.metadata.version("pytest"), although pytest is not listed as a runtime dependency in pyproject.toml. The documented setup installs requirements.txt, so this currently works, but installing only the package could make selection/evaluation fail.
